# Workout Tracker (Aplicativo de Treino)

A simple workout tracking application built with React, TypeScript, and Vite.

## Getting Started

### Prerequisites

- Node.js >= 18

### Install dependencies

```bash
npm install
```

### Development

```bash
npm run dev
```

The app runs at `http://localhost:5173` by default.

### Lint

```bash
npm run lint
```

### Test

```bash
npm test
```

### Build

```bash
npm run build
```
